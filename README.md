# radar-labs site source

This repository is the **source** of <https://sjdfi0wjvosdju9.github.io> — a static site publishing
public salary ranges from 266 companies (8,040 postings, CC BY 4.0).

- Dataset: <https://sjdfi0wjvosdju9.github.io/salary-data.html>
- Company lookup: <https://sjdfi0wjvosdju9.github.io/lookup.html>
- Open data repo: <https://github.com/sjdfi0wjvosdju9/job-salary-open-data>
- Hosted API (paid): <https://apify.com/contributory_garnet_hyz/ats-job-feed>

All pages are generated by the pipeline described at
<https://sjdfi0wjvosdju9.github.io/how-we-choose.html>. Data CC BY 4.0, code MIT.
