1. Get a token

Free Apify account → Settings → Integrations → API token. The dataset CSV needs no account at all; the API does.

2. Call it

curl -s -X POST \
  "https://api.apify.com/v2/acts/zqBGjpzG8z3UZxN51/runs?token=$APIFY_TOKEN&waitForFinish=300" \
  -H "Content-Type: application/json" \
  -d '{"useVerifiedPool": true, "salaryOnly": true, "maxJobs": 50, "maxPerCompany": 2, "maxWorkers": 6}'

Prefer the console? https://apify.com/contributory_garnet_hyz/ats-job-feed

4. Why the numbers can be trusted

  • Salaries are normalised, not guessed. Structured fields first (Ashby summaryComponents, Lever salaryRange); only then a text window around pay-cue phrases.
  • Implausible values are dropped, not clamped. Anything outside $5k–$5M a year after normalisation is removed entirely, so the tail is missing rather than wrong.
  • Currency uses a daily rate and the original local range is kept in salaryLocal*, so you can re-derive it yourself.
  • Ranges are ranges. These are published bands, not what anyone was actually paid — 43% of the 18,668 postings we read publish nothing at all.
